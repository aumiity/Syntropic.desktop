ของดีที่น่าดึงมาใช้

  • Neutral soft surfaces — muted/accent/secondary เป็นเทากลาง ไม่ติดสี → ตรงกับ Direction B ที่เราคุยกัน (แก้ปัญหาสี soft จัด/neon)
  • Border โปร่ง — dark ใช้ oklch(1 0 0 / 10%) (ขาว 10%) แทนสีตายตัว ปรับตามพื้นเอง
  • เทา "อุ่น" นิด ๆ — neutral มี chroma ต่ำ ๆ (hue ~34–56 = stone) ไม่ใช่เทาเย็นซีด
  • Radius 10px — กลมกว่าเรา (8px) นิดเดียว ดูนุ่มขึ้น
  • Font Inter — ตรงกับเราอยู่แล้ว
