# DRAFT — Barcode Sticker + A4 Price Tag Printing (machine plan)

> Scratch draft for audit. Final deliverable = docs/plans/Barcode_Price_Tag_Printing.html

## Goal

เพิ่ม tab ที่ 3 ในหน้าสินค้า (`/products/print`) สำหรับงานพิมพ์ 2 โหมด:

1. **สติ๊กเกอร์บาร์โค้ด** — พิมพ์ด้วยเครื่อง/กระดาษ**เดียวกับฉลากยา** (อ่าน `printer_name`, `width_mm`, `height_mm`, `pad_*`, `font_family` จาก `label_settings` ตรง ๆ — ไม่มีค่ากระดาษแยก) ใน 1 หน้าวาง grid หลายดวง (cols×rows ตั้งได้) แต่ละช่องเลือกสินค้า+หน่วยอิสระ
2. **ป้ายราคา A4** — พิมพ์ด้วยเครื่องจาก `document_settings.printer_name`, หน้า A4 ตายตัว (ไม่สน `document_settings.paper_size`), grid ตั้งได้, ราคาตัวใหญ่

ทั้งสองโหมด: UX เดียวกัน (grid-cell assignment), ปุ่มคัดลอกช่องแรก→ทุกช่อง, ช่องว่างเว้นได้, จำนวนสำเนา, preview สด 1:1, ปุ่มดูตัวอย่าง PDF, layout config persist ลง DB singleton

## Steps (dependency order: 1→2→3→4→5→6→7→8)

### Step 1 — Schema: 2 ตาราง singleton ใหม่ (`electron/db/schema.ts`)

วาง CREATE TABLE IF NOT EXISTS ต่อจาก `document_settings` (~line 573) ตาม pattern พี่น้อง (`receipt_settings`/`document_settings`):

```sql
-- Barcode sticker sheet layout (singleton). Paper/printer comes from
-- label_settings (same physical printer + die-cut paper as drug labels) —
-- this table only stores the GRID + per-cell content style. Columns map 1:1
-- to the renderer form keys (dynamic-SQL save).
CREATE TABLE IF NOT EXISTS barcode_sticker_settings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  grid_cols        INTEGER NOT NULL DEFAULT 2,
  grid_rows        INTEGER NOT NULL DEFAULT 2,  -- 2×2 บนกระดาษ default 80×50 → ช่อง ~36×20mm พอดีเนื้อหา default โดยไม่ shrink (audit R1-7)
  gap_x_mm         REAL NOT NULL DEFAULT 2,
  gap_y_mm         REAL NOT NULL DEFAULT 2,
  show_name        INTEGER NOT NULL DEFAULT 1,
  show_price       INTEGER NOT NULL DEFAULT 1,
  show_digits      INTEGER NOT NULL DEFAULT 1,
  font_size_name   REAL NOT NULL DEFAULT 7,   -- pt
  font_size_price  REAL NOT NULL DEFAULT 8,   -- pt
  font_size_digits REAL NOT NULL DEFAULT 7,   -- pt
  barcode_height_mm REAL NOT NULL DEFAULT 8,
  updated_at TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);

-- A4 price-tag sheet layout (singleton). Printer comes from document_settings
-- (printer_name only — page is FIXED A4 by requirement, paper_size ignored).
CREATE TABLE IF NOT EXISTS price_tag_settings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  grid_cols        INTEGER NOT NULL DEFAULT 3,
  grid_rows        INTEGER NOT NULL DEFAULT 8,
  gap_x_mm         REAL NOT NULL DEFAULT 0,
  gap_y_mm         REAL NOT NULL DEFAULT 0,
  page_margin_mm   REAL NOT NULL DEFAULT 8,
  show_name        INTEGER NOT NULL DEFAULT 1,
  show_price       INTEGER NOT NULL DEFAULT 1,
  show_barcode     INTEGER NOT NULL DEFAULT 0,
  show_code        INTEGER NOT NULL DEFAULT 0,
  show_unit        INTEGER NOT NULL DEFAULT 1,
  show_cut_lines   INTEGER NOT NULL DEFAULT 1,
  font_size_name   REAL NOT NULL DEFAULT 12,  -- pt
  font_size_price  REAL NOT NULL DEFAULT 24,  -- pt
  font_size_meta   REAL NOT NULL DEFAULT 9,   -- pt (code/unit line)
  barcode_height_mm REAL NOT NULL DEFAULT 10,
  font_family      TEXT NOT NULL DEFAULT 'Sarabun',
  updated_at TEXT NOT NULL DEFAULT (datetime('now','localtime'))
);
```

- ตารางใหม่ทั้งคู่ → ไม่ต้องมี ALTER migration (CREATE IF NOT EXISTS รันทุก boot)
- Invariant: **form keys = column names เป๊ะ** (dynamic SQL UPDATE จาก `Object.keys`) → docs/claude/database.md

### Step 2 — IPC handlers (`electron/ipc/settings.ts`)

เพิ่ม 4 handlers ตาม **ensure-row-then-UPDATE pattern ของ `receipt_settings`** (settings.ts:421-450 — อย่า copy pattern ของ `saveLabelSettings` ที่มี INSERT-DEFAULT-then-skip-payload bug):

**การตัดสินใจเรื่อง requireAdmin: ไม่ใส่** บน save 2 ตัวนี้ (ข้อยกเว้นจาก pattern "settings writes admin-gated") — เหตุผล: เป็น layout preference ของงานพิมพ์หน้าร้านที่ staff เป็นผู้ใช้หลัก, ไม่มีผลการเงิน/ความปลอดภัย, และหน้า print auto-persist ตอน config เปลี่ยน (ถ้า gate admin → staff ใช้งานแล้ว FORBIDDEN toast รัว ๆ)
- **(audit R1-1) deviation ต้องครบทั้ง 2 ฝั่ง:** (a) ใส่ comment อธิบายที่ handler ทั้งสอง และ (b) **Step 7 ต้องแก้ `docs/claude/ipc-api.md` (บรรทัด "settings writes admin-only" ~line 41)** ให้ carve-out `saveBarcodeStickerSettings`/`savePriceTagSettings` พร้อมเหตุผลสั้น ๆ — ห้ามปล่อยให้ doc กับ code ขัดกัน

### Step 4 — Renderer lib (`src/lib/tags/`)

ไฟล์ใหม่ 3 ไฟล์ — reuse ของเดิมให้มากที่สุด:

**`src/lib/tags/types.ts`**
```ts
export interface BarcodeStickerForm { /* keys = barcode_sticker_settings columns (ยกเว้น id/updated_at) */ }
export interface PriceTagForm { /* keys = price_tag_settings columns */ }
export const BARCODE_STICKER_DEFAULTS: BarcodeStickerForm = { ... }
export const PRICE_TAG_DEFAULTS: PriceTagForm = { ... }
// 1 ช่องที่ถูก assign แล้ว (null = ช่องว่าง)
export interface TagCell {
  product_id: number
  name: string          // trade_name
  unit_name: string
  price: number         // price_retail ของหน่วยที่เลือก
  code: string          // products.code
  barcode: string       // resolved: unit.barcode → product.barcode → product.code

```

**`src/lib/tags/stickerHtml.ts`** — `buildBarcodeStickerHtml(paper: LabelSettingsForm, cfg: BarcodeStickerForm, cells: (TagCell|null)[], copies: number): Promise<string>`
- `@page { size: ${paper.width_mm}mm ${paper.height_mm}mm; margin: 0 }` + body padding จาก `paper.pad_*` ต่อหน้า (mirror `buildLabelSheetHtml` ใน `src/lib/label/html.ts:139-171`)
- หน้า = `display:grid; grid-template-columns: repeat(cols,1fr); grid-template-rows: repeat(rows,1fr); gap: gap_y gap_x` + `break-after:page` ระหว่างหน้า; วน `copies` หน้า (เนื้อหาเหมือนกันทุกหน้า), clamp copies 1..50
- แต่ละช่องที่มีของ: `<div class="label-area"><div class="label-fit">…</div></div>` → **reuse `LABEL_FIT_SCRIPT`** (`src/lib/label/fit.ts` — script วนทุก `.label-fit` อยู่แล้ว จึงได้ per-cell shrink-to-fit ฟรี และ `printer:printLabel`/`previewLabelPdf` await `window.__labelFitReady` อยู่แล้ว)
- ช่องว่าง (cell=null) = `<div></div>` เปล่า
- เนื้อหาช่อง: ชื่อ (clamp 2 บรรทัด), แท่งบาร์โค้ด = `barcodeSvg(cell.barcode, {displayValue:false})` (จาก `src/lib/label/barcode.ts`) ใน box สูง `barcode_height_mm` กว้าง 100% ของช่อง, ตัวเลขบาร์โค้ดเป็น div แยก (toggle `show_digits`, font `font_size_digits`pt), ราคา `font_size_price`pt ตัวหนา
- ฟอนต์: `buildPrintFontFaceCss(paper.font_family)` (จาก `@/lib/print/fonts`) + `esc()` ทุก text

**`src/lib/tags/priceTagHtml.ts`** — `buildPriceTagHtml(cfg: PriceTagForm, cells: (TagCell|null)[]): Promise<string>`
- `@page { size: A4; margin: 0 }`, body 210×297mm, padding `page_margin_mm`
- grid เหมือนกัน; `show_cut_lines` → เส้นขอบช่อง `0.3pt solid #000` (ทุกช่องรวมช่องว่าง เพื่อให้ตัดเป็นตาราง)
- เนื้อหาป้าย: ชื่อ (กลาง, clamp 2 บรรทัด), ราคา `font_size_price`pt bold + "บาท", บรรทัด meta = รหัส/หน่วย (`font_size_meta`), บาร์โค้ดเล็ก (optional)
- ใส่ `LABEL_FIT_SCRIPT` + wrap ช่องด้วย `.label-area/.label-fit` เหมือนกัน
- **(audit R1-2) แก้ `electron/ipc/printer.ts` เพิ่ม optional fit-await ทั้ง 2 จุด:** ต่อท้าย `WAIT_FOR_RENDER_JS` consumer ของ **`printer:printHtml` (line ~261)** และ **`printer:previewHtmlPdf` (line ~303)** ด้วย `if (window.__labelFitReady) { try { await window.__labelFitReady } catch {} }` (copy แบบ printLabel line 174) — backward-safe: caller เดิม (`src/lib/receipt/print.ts`) ไม่เคยตั้ง `__labelFitReady` → เป็น no-op (ยืนยันแล้วใน audit R1)
- **transformOrigin caveat (audit R1-8):** fit script scale จาก `top left` (fit.ts:60) — ป้ายที่ล้นจะหดชิดมุมซ้ายบนของช่อง ยอมรับเป็น overflow behavior (defaults ออกแบบให้ไม่ล้นอยู่แล้ว ช่อง A4 ใหญ่); จัดเนื้อหากึ่งกลางด้วย flex ภายใน `.label-fit` ตามปกติ
- copies ไม่อยู่ใน HTML — ส่งผ่าน `printHtml({copies})` (cap 20 ที่ `electron/ipc/printer.ts:268`)
