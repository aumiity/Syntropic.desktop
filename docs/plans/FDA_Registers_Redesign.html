1 ภาพรวม — ทำอะไร ทำไม

ปัญหาวันนี้: รายงาน อย. ทั้ง 3 แทป เปิดมาเป็น "พรีวิว A4" เต็มหน้าเลย มองภาพรวมรายการเป็นตารางไม่ได้ และตัดผู้จำหน่ายรายย่อยที่ไม่อยากให้ขึ้นรายงานไม่ได้

แนวคิดที่พี่ต้องการ (ทั้ง 3 แทปแนวเดียวกัน): โชว์รายการเป็น ตารางก่อน แล้วค่อยกดพิมพ์เพื่อ "จัดระเบียบลงแบบฟอร์ม อย." ในกล่องพรีวิว

  • หน้าหลักทุกแทป = ตารางเต็มความสูง เลื่อนรายการในตัวตาราง หัวตาราง sticky ค้างไว้ (เหมือนหน้าสินค้า ProductsList)
  • ข.ย.๙ (ซื้อยา): ตารางแบน + ตัวกรอง "ผู้จำหน่าย" (เช็คลิสต์ + ค้นหา + เลือกทั้งหมด/ล้าง) ติ๊กออก = รายการของรายนั้นไม่ถูกพิมพ์ (แถวในตารางจางลง)
  • ข.ย.๑๐/๑๑ (ขายยา): ตารางแบนแถวเดียว (1 แถว = 1 รายการขาย: วันที่ขาย/ชื่อยา/ล็อต/ได้มาจาก/จำนวน/ผู้ซื้อ) — ไม่มีตัวกรอง ตอนพิมพ์ค่อยจัดกลุ่มเป็นล็อตตามฟอร์มเดิม
  • กด "พิมพ์" (ทุกแทป): เปิด กล่องพรีวิวเดียวกัน (shared) โชว์ A4 จริงทีละหน้า + เลือกหน้า (เช่น 1-3,5) + จำนวนชุด (เริ่ม 1) แล้วพิมพ์เงียบไปเครื่อง A4
  • "ฟอร์มเปล่า" ยังอยู่บน toolbar ของทุกแทป เหมือนเดิม

ขอบเขต: ไม่แตะฐานข้อมูล/IPC เลย · ฟอร์มพิมพ์ของ ข.ย.๑๐/๑๑ (จัดกลุ่มรายล็อต) เหมือนเดิมเป๊ะ — เปลี่ยนแค่ "หน้าจอเป็นตาราง" + "ย้ายพรีวิวไปอยู่ในกล่องพิมพ์"
