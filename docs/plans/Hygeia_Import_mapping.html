นำเข้า map เข้าตารางเรา ทางเลือก รอพี่ตัดสินใจ generate สร้างใหม่ตอน import ข้าม ไม่นำเข้า

0หลักการนำเข้า

  • One-off script — สคริปต์นำเข้าครั้งเดียว (เช่น scripts/import-hygeia.ts) ไม่แตะ runtime ของแอป รันบน DB เปล่า
  • Key crosswalk — เก็บ map HygeiaKey → SyntropicId ในหน่วยความจำระหว่าง import (เช่น ItemKey 1536 → products.id 1) แล้วใช้ผูก foreign key ต่อ ๆ ไป
  • Code ใหม่ทั้งหมด — ไม่เก็บ IT-xxxx / CT-xxxx เดิม แต่ generate รหัสตามรูปแบบเรา (เก็บรหัสเดิมไว้ใน note ได้ถ้าต้องการ)
  • ลำดับ import: หน่วย/หมวด/ประเภท → สินค้า → ล็อต → ลูกค้า/ซัพ → รับซื้อ → ขาย (เคารพ FK)
  • กรอง 3 ปี: SaleBasicHeader.DocDT >= 2023-06-05 (รูปแบบวันที่ใน mdb = MM/DD/YY) ทั้งฝั่งขายและซื้อ

★เคสพิเศษที่ตรวจแล้ว (ตามที่พี่เตือน)

① หน่วยใหญ่ (กล่อง / โหล / แพ็ค) — ตรวจครบ ✓

Hygeia เก็บหน่วยฐานบนตัวสินค้า (Item.SaleUnitName) ส่วนหน่วยใหญ่อยู่ใน ItemUnit พร้อม Multiply (เช่น กล่อง×10, โหล×12, TYLENOL กล่อง×20) — ตรงปรัชญาเราเป๊ะ: หน่วยฐานบน products.unit_id, หน่วยย่อยใน product_units.qty_per_base.
เวลาขาย: SaleBasic.UnitName + Multiply + UnitQty → จำนวนฐาน = UnitQty × Multiply, และ SaleBasicLot.BaseQty คือยอดตัดสต็อกจริงต่อล็อต (FEFO)

② สินค้าจัดชุด (ItemSet) — ตรวจครบ ✓ มี 33,803 บรรทัดขายแบบชุด

Hygeia ไม่เก็บชุดเป็นบรรทัดเดียว — ตอนขายมัน แตกออกเป็นบรรทัดสินค้าจริงทีละตัว ทุกบรรทัด tag ด้วย ItemSetKey / ItemSetCode (เช่นชุด IS-0000005 = PHEMINE + TERCO-D + BROMCOLEX → 3 บรรทัด).
ผลต่อการนำเข้า: ประวัติขายแต่ละบรรทัด = สินค้าจริง 1 ตัว → ลง sale_items ตรง ๆ (qty/ราคาครบ). "ชุด" เป็นแค่ป้ายจัดกลุ่ม — เก็บรหัสชุดไว้ใน sale_items.item_note ได้ถ้าอยากรู้ที่มา.
ส่วน นิยามชุด (ItemSet 93 ชุด / ItemSetItem 311) → map เป็น products(is_bundle=1) + product_bundle_items ได้ ทางเลือก (ไว้ขายชุดต่อในอนาคต) — แยกจากประวัติขาย

7ขอยืนยัน 4 ข้อก่อนเขียน importer

  1. นิยามชุด (ItemSet 93 ชุด) — import เป็นสินค้าจัดชุด (is_bundle) ไว้ขายต่อไหม? หรือเอาแค่ประวัติขายที่แตกบรรทัดแล้วพอ?
  2. บิลที่ถูกยกเลิก (IsCanceled=1) ในช่วง 3 ปี — เก็บไว้เป็น status 'voided' หรือข้ามทิ้ง?
  3. เครดิต/ลูกหนี้ค้างชำระ — เอาแค่ยอดสรุปในบิล (พอ) หรืออยากได้ตาราง SaleCredit ละเอียดด้วย?
  4. เป้าหมาย DB — สร้างไฟล์ .db ใหม่สำหรับทดสอบ (แนะนำ) หรือเขียนทับ DB ที่ใช้อยู่?
