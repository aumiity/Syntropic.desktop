ส่งออก Excel (.xlsx)

เพิ่มการส่งออกข้อมูลบิลขาย บิลซื้อ รายงาน VAT และค่าใช้จ่าย เป็นไฟล์ Excel — ผ่านปุ่มในแต่ละหน้า + หน้าศูนย์รวมส่งออก

1 ภาพรวม — ทำอะไร ทำไม

ปัญหา: ตอนนี้ข้อมูลในระบบ (บิลขาย/ซื้อ รายงานต่าง ๆ) ดูได้แต่ในแอป เอาออกไปทำบัญชี ส่งสรรพากร หรือวิเคราะห์ต่อใน Excel ไม่ได้

แผนนี้แก้: เพิ่มความสามารถ "ส่งออก Excel" โดยใช้ไลบรารี exceljs ที่ติดตั้งอยู่แล้วในโปรเจกต์ (v4.4.0 — ไม่ต้อง npm install เลย ความเสี่ยง better-sqlite3 พังจึงไม่มี). มี 2 ทางเข้าใช้งาน — ปุ่ม "ส่งออก Excel" ในแต่ละหน้า และหน้าศูนย์รวมส่งออก

เสร็จแล้วได้: กดปุ่มเดียว ได้ไฟล์ .xlsx จริง (ไม่ใช่ CSV ที่ barcode/วันที่เพี้ยน) — บิลออกมาเป็น 2 ชีต (หัวบิล + รายการสินค้า), วันที่เป็น DD/MM/YYYY, barcode/เลขล็อตเป็นข้อความไม่กลายเป็น 8.4E+11

4 ส่งผลอย่างไร

ข้อดี

  • ไม่ต้องลงแพ็กเกจใหม่ — exceljs มีอยู่แล้ว ความเสี่ยง better-sqlite3 พัง = 0
  • ใช้โครงเดิม (showSaveDialog + handler pattern ของ matcher) ต่อยอดน้อย
  • รายงานเกือบทุกตัวมี query อยู่แล้ว (salesList limit:'all', vatSummary, purchase:history) — ดึงครบได้ทันที
  • ปุ่มในหน้า + ศูนย์รวม ใช้ handler ฝั่ง main ตัวเดียวกัน — เขียนครั้งเดียวใช้ 2 ที่

ข้อเสีย / ต้นทุน

  • วันที่เก็บเป็นข้อความ DD/MM/YYYY → Excel sort ตามวันที่ไม่ได้ (แลกกับกฎรูปแบบวันที่เดียวทั้งแอป — ยอมรับ)
  • ต้อง refactor core ของ vatSummary/expenses:list เป็นฟังก์ชันใช้ร่วม (ระวัง return shape เดิมต้องไม่เปลี่ยน)
  • ช่วงวันที่กว้างมาก (หลายหมื่นแถว) จะกินหน่วยความจำ/เวลาบ้าง — เฟสนี้รับได้ ค่อย stream ทีหลัง

ข้อควรระวัง (invariant)

  • ห้าม npm install เปล่า — exceljs มีอยู่แล้ว; เช็ค better_sqlite3.node หลัง build
  • requireAdmin(e) คือการ์ดจริง — บรรทัดแรกของทุก handler การเงิน; ซ่อนปุ่ม = UX เท่านั้น
  • route /reports ไม่ได้ guard — staff พิมพ์ URL เข้าหน้า hub ได้ → หน้า hub ต้อง self-gate ด้วย isAdmin
  • แก้ .ts เท่านั้น — vite.config.js/.d.ts, preload.js เป็น build artifact
  • barcode/ล็อต/tax_id = cell ข้อความ (numFmt='@'); ยอดเงิน = number จริง (SUM ได้)
  • ไม่มี emoji ในข้อความที่ ship; ปุ่ม/ตัวกรองตามกฎ filter strip h-12 / control h-9

5 UX / UI

  • ปุ่มในหน้า: ปุ่มไอคอน Download (lucide) แบบ variant="elevated" วางในแถบตัวกรอง (h-12, ปุ่ม h-9 w-9 p-0) ข้างปุ่ม "จัดการตาราง" — มี tooltip="ส่งออก Excel". สำหรับหน้า ภาษี วางในแถบ toolbar ของ TabStrip ข้าง MultiDatePicker
  • ปุ่มโผล่เฉพาะ admin (usePermission().isAdmin) — staff ไม่เห็นปุ่มการเงินเลย
  • หน้าศูนย์รวมส่งออก (/reports/export): MultiDatePicker ร่วม (ดีฟอลต์เดือนนี้) + รายการ dataset เป็นแถว (ไอคอน + ชื่อไทย + คำอธิบายสั้น + ปุ่มส่งออก). ถ้าไม่ใช่ admin โชว์สถานะ "เฉพาะผู้ดูแล"
  • หลังกด: เปิดกล่องบันทึกไฟล์มาตรฐานของ Windows/Mac → สำเร็จ toast เขียว (โชว์ path), ยกเลิก = เงียบ, ผิดพลาด = toast แดง
  • primitive ใหม่ src/components/ui/export-button.tsx (ไม่ทำ helper ในหน้า ตามกฎ) — โหลดดิ้งระหว่างเขียนไฟล์, จัดการ {ok,path,canceled} + toast เอง
  • ทุกข้อความภาษาไทย, สีตาม semantic token; หัวชีตในไฟล์ Excel = ตัวหนา + แช่แถวบน + autofilter

Add an "Export to Excel (.xlsx)" capability using exceljs (already a dep, v4.4.0 — NO npm install). Two entry points: per-page "ส่งออก Excel" buttons + a central Export Hub. Phase-1 datasets (all finance, admin-only): sales bills, purchase bills (GR), VAT report, expenses. Bills export as a 2-sheet workbook (header + line items).
