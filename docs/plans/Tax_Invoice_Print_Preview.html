ใบกำกับภาษี — Popup Preview + ตัด A5 (เฟส 3)

เปลี่ยนใบกำกับภาษีเป็น popup พรีวิว A4 (React A4Sheet เหมือน GR/ข.ย.) เลิกใช้ HTML builder, ตัด A5 ออกทั้งระบบ → A4 อย่างเดียว, คงล็อกต้นฉบับทางกฎหมาย + buyer อ่านอย่างเดียว

ผ่าน audit 2 รอบ (ไม่มี P0/P1 ค้าง) เฟส 3 · A4 only 2026-06-19

1 ภาพรวม — ทำอะไร ทำไม

วันนี้ใบกำกับภาษีสร้างจาก buildTaxInvoiceHtml (HTML string) แล้วพิมพ์เงียบ ส่วนพรีวิวมีแต่ปุ่ม "ดูตัวอย่าง PDF" (ถูกลบไปแล้วในเฟส 1).

แผนนี้เปลี่ยนใบกำกับให้เป็น popup พรีวิว A4 แนวตั้ง ด้วยกลไกเดียวกับ GR/ข.ย. (React A4Sheet + printDomSheets + ReportPrintDialog) — ซูม/พลิกหน้า/กำหนดหน้า/จำนวนชุดได้, ที่เห็น = ที่พิมพ์ 1:1, ไม่มีปุ่ม PDF.

แผ่นใบกำกับ React ตัวเดียว (taxInvoiceSheet.tsx) ใช้ ทั้งหน้าพิมพ์จริง และพรีวิวหน้า DocumentSettingsTab → จึง ลบ buildTaxInvoiceHtml ทิ้งทั้งหมด (พรีวิวตั้งค่า = ของพิมพ์จริง ไม่เพี้ยน).

ตัด A5 ออกทั้งระบบ (DocumentSettings + PrintTab) → ใช้ A4 ขนาดเดียว สะดวกกว่า; column paper_size เก็บเป็น DEAD (บังคับ A4, ลบก่อน launch).

คงของเดิมที่ห้ามแตะ: buyer อ่านอย่างเดียว (ไม่มี picker) + ล็อกต้นฉบับทางกฎหมาย (พรีวิวไม่เผาต้นฉบับ; ล็อกหลังพิมพ์ต้นฉบับสำเร็จเท่านั้น).

  • ล็อกต้นฉบับ (P0): พรีวิวใช้ transient record (ห้าม issueOrGet); confirmOriginalPrinted เฉพาะใน if(res.success && !copy); copy มาจาก issueOrGet ไม่ใช่ alreadyOriginal
