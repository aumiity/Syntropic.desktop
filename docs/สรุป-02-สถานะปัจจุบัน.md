## ข้อควรรู้ก่อนรัน/build

- รัน dev: `npm run electron:dev`
- ⚠️ **ห้าม `npm run`/`npm install` เฉยๆ** — rebuild native module ทำ better-sqlite3 prebuilt พัง
- เพิ่ม lib: `npm install <pkg> --ignore-scripts` แล้วเช็ค `node_modules/better-sqlite3/build/Release/better_sqlite3.node` ยังอยู่
- **ก่อน production build ต้องลบ DEV-only code:**
  - ปุ่ม "ดูตัวอย่าง Setup (DEV)" ใน `src/pages/Settings/ShopTab.tsx` (3 จุด tag `DEV ONLY`)
  - DEV auto-login (`auth:devLogin` + LoginGate DEV path)
  - test data ใน `seed.ts` (PRODUCTS/CUSTOMERS)

➡️ ดูรายการระบบที่เสร็จทั้งหมด: [[สรุป-03-ระบบที่ทำเสร็จแล้ว]]
