4 · หยิบมาทำ dark mode เราดีไหมเอา / ไม่เอา

ยืมได้ดี

  • ระบบบทบาทสี — accent เดียวเด่น + 4 สีสถานะ ตรงแนวเรา (primary + success/destructive/info/warning) อยู่แล้ว
  • พื้นเข้มอมอุ่น #1a1918 + ตัวอักษรครีมหม่น #d1cfc5 สบายตากว่า dark เทากลาง
  • border/hover แบบ overlay โปร่ง ปรับตามพื้นได้เอง

ไม่เอาตามตรง

  • ฟอนต์ mono + ลุค ASCII (█ ░ ▸ ─) เป็นคาแรกเตอร์ terminal เฉพาะหน้ารายงาน ไม่เข้ากับ POS (Sarabun/Inter)
  • tabular-nums — กฎเราห้าม
  • hex ดิบ — ต้องผ่าน semantic token (src/index.css + tailwind.config.js) ห้ามใส่ตรง component
ถ้าจะทำจริง: เลือกก่อนว่าจะคง brand teal+yellow ของเรา หรือทดลอง accent อุ่นแบบ clay → ปรับ .dark ใน src/index.css → เทียบ /theme (SSOT) ทุกจุด → อ่าน docs/claude/ui-theming.md ก่อนแตะ component
