# 🔒 กฎเหล็กสถาปัตยกรรม (HARD invariants)

> กลับไป [[สรุป-00-สารบัญ]] · กฎที่ห้ามแหก — แต่ละข้อมี incident อยู่เบื้องหลัง
> รายละเอียดเต็ม + failure mode อยู่ใน `docs/claude/*.md`

---

## 🗄️ Database & Business Logic

- **Allow-list ทุก save payload — ห้าม spread `...form` ดื้อๆ** · `products:update` สร้าง SQL จาก `Object.keys(data)` → key ที่ไม่ใช่คอลัมน์ทำทั้ง UPDATE พัง (`no such column`)
- **Walk-in customer = row จริง C0000 ไม่เคยเป็น NULL** · backend ผ่าน `walkInCustomerId(db)`; renderer เก็บ `null` เป็น marker ใน memory เท่านั้น
- **Base unit อยู่ที่ `products.unit_id`** · `product_units` เก็บแค่หน่วยที่ไม่ใช่ base; ไม่มี flag `is_base_unit`; POS synthesize base ด้วย `id: -1`
- **Front-end ห้าม coerce blank → 0** สำหรับ stock/cost · `parseFloat('') || 0` ลบข้อมูลเงียบๆ → validate: blank/NaN/negative → toast + abort
- **`is_closed` บน lot auto-toggle เมื่อ qty ข้าม 0** · ไม่งั้น FEFO/availability query (filter `is_closed=0`) จะหาย lot เงียบๆ

## 🎨 UI & Theming

- **ห้าม emoji ใน output โปรแกรม** (source code, UI string, runtime text) → ใช้ lucide-react + Badge variants + semantic token · (emoji OK ในเอกสาร/แชต/plan)
- **`/theme` = source of truth** · ก่อนเพิ่ม/แก้ UI เปิด `src/pages/Theme/index.tsx` หา pattern ที่ตรง แล้วทำตาม; แก้ primitive ต้องอัปเดต showcase ในคอมมิตเดียวกัน
- **ELEVATED = default ของ input แล้ว** · `<Input>`/`<Textarea>`/`<SelectTrigger>` เปล่าๆ ถูกแล้ว — เลิกเติม `variant="elevated"` มือ · flat look opt-in ด้วย `variant="filled"` · **Button ไม่โดน** (default = teal CTA)
- **ห้ามใช้ Tailwind palette literal** (`bg-blue-500`, `text-slate-600`) · ใช้ semantic token เท่านั้น (`bg-primary`, `bg-success-soft`) · ขาด role → เพิ่ม token ใน `src/index.css` + `tailwind.config.js`
- **Tailwind v3 CSS var = bracket เท่านั้น** · ✅ `w-[var(--x)]` ❌ `w-(--x)` (v4 shorthand ถูก drop เงียบ)
- **ห้ามเขียน raw HTML UI element** · ใช้ `src/components/ui/` เสมอ; ขาด variant → เพิ่มในไฟล์ component
- **ห้ามมี local UI helper ใน `src/pages/`** · reusable → ใส่ `src/components/ui/` (มี `SectionCard`, `FormField`, `NativeSelect`, `Toggle`)
- **Modal contract:** outside-click ไม่ปิด · Esc ปิด · Enter = primary OK · ทุก `<DialogContent>` ต้องมี Header+Title+Body+Footer
- **Icon ใน `<Button>` ใช้ `size-N` ไม่ใช่ `h-N w-N`** · rule `:not([class*='size-'])` ใน `button.tsx` snap เป็น 16px เงียบๆ
- **Text-size ตามบทบาท:** title ≥ `text-base` · body/table/label/button = `text-sm` · helper/caption/badge = `text-xs` · **ห้ามเล็กกว่า `text-xs`**
- **ใช้พาเลตเต็ม** อย่ากองที่ primary/secondary/destructive · มี `accent`(เหลือง)/`primary-soft`/`info-soft`/`warm`/`success`/`outline`/`ghost`/`destructive2` + ตระกูล `*-outline`
- **Scrollbar บาง 6px ทุกที่** ขนาดเดียว ไม่มีข้อยกเว้น
- **Table-card มี 4 background zone** · header band เท่านั้นที่ `bg-muted`; status bar = `border-t` only · row action = square `size="icon-lg" variant="elevated"` (ไม่ tint ตามบทบาท)
- **กฎความสูง (HARD ใหม่ รวบเป็นกฎเดียว):** ทุก bar = `h-12`, ทุก component ข้างใน = `h-9` — ไม่มีข้อยกเว้น · กฎเก่า filter strip `h-14`/`h-10` **ตายแล้ว**
- **Sortable table:** ต้อง gate ด้วย toggle, draft local, commit/cancel explicit, backend renumber ใน 1 transaction · ห้าม persist ตอน `onDragEnd`
