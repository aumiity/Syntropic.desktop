## 📌 โปรเจคนี้คืออะไร

แอป **Pharmacy POS + คลังสินค้า + เอกสารราชการ (อย.)** สำหรับร้านขายยาขนาดเล็ก-กลางในไทย รันแบบ **offline เต็มตัว** บนเครื่องร้านเอง

- **ชื่อโปรแกรม:** Rx Desktop (บริษัท = Syntropic; สาย product = Rx Desktop / Web / CLI / Code)
- **Stack:** Electron 31 + React 18 + Vite 5 + TypeScript + better-sqlite3 + Tailwind + Zustand
- **ที่มา:** rebuild จากของเดิม Laravel/Blade/MySQL PHP (`D:\Syntropic.Project\Syntropic.php`)
- **ภาษา UI:** ไทยทั้งหมด · ผู้ใช้ = เภสัชกร/ผู้ช่วย (ไม่ technical)
- **รัน:** `npm run electron:dev` · ⚠️ **ห้าม `npm install`** (พัง better-sqlite3 prebuilt) → ใช้ `npm install <pkg> --ignore-scripts`
