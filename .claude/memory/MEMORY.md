- [Min text size = text-sm](feedback_text_size.md) — `text-xs` and arbitrary smaller values (`text-[10px]` etc) forbidden in new code. Codified in CLAUDE.md theming rule #9.
- [tsc discipline](feedback_tsc_discipline.md) — don't run tsc after every edit; skip for markup/className/text-only changes (Vite hot-reload covers them); only type-check type/logic/import changes when genuinely unsure.
- [Animation reduced-motion pitfall](feedback_animation_reduced_motion.md) — `onAnimationEnd` ไม่ยิงภายใต้ `prefers-reduced-motion` → flag ค้างถาวร; ใช้ `setTimeout`+cleanup ใน `useEffect` แทนเสมอ
- [Modifier vs className specificity](feedback_modifier_className_specificity.md) — `className="h-9"` ฯลฯ แพ้ base modifier (`group-data-[…]:h-8`) ใน cva primitive เพราะ specificity ไม่ใช่ source order; override ต้องตั้งระดับ modifier เดียวกัน (incident: toggle tabs สูง 30 ไม่ใช่ 36)
- [Popover/Combobox scroll in Dialog](feedback_popover_scroll_in_dialog.md) — portaled popover list ใน Dialog scroll ไม่ได้ (react-remove-scroll ดัก wheel ที่ document); fix = `onWheel/onTouchMove` → `stopPropagation()` ที่ลิสต์ (ทำใน combobox.tsx แล้ว)
- [TabStrip row = h-10](feedback_tabstrip_height_h10.md) — **2026-06-11** — แถบ TabStrip (แท็บ+ปุ่ม ใต้ PageHeader) ≠ table-bar; อ้างอิง segmented control = **40px (h-10)** → ปุ่มที่ยืนคู่ = h-10 ไม่ใช่ h-9; tabs.tsx ฝัง h-10 ที่ระดับ modifier (h-auto เดิม + className h-9 = dead class), ล้างทั่วแอปแล้ว
